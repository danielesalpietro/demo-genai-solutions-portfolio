# OPENCLAW Adapter

The authoritative instructions are in `AGENTS.md`.

Before changing the repository:

1. Read `AGENTS.md`, `CONTRIBUTING.md`, the linked Issue, and the nearest local instructions.
2. Work only on an issue-linked branch.
3. Keep changes scoped and auditable.
4. Run `make validate` and the applicable smoke test.
5. Submit a Pull Request. Never bypass required checks or push to `main`.
