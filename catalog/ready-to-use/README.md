# Ready to Use

Demos in this directory satisfy the full demo contract:

- `make validate` passes
- `make smoke DEMO=<name>` passes
- Documentation is complete
- Human maintainer has reviewed and approved

Each demo folder contains:
- `description.md` — scenario, capabilities, upstream provenance
- `release_notes.md` — version history and hardware/software prerequisites

The corresponding implementation is under `demos/<name>/`.
