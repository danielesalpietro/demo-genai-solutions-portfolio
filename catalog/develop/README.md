# In Development

Demos in this directory have an open GitHub Issue, confirmed acceptance criteria, and an active development branch.

Each demo folder is moved here from `catalog/candidate/` when development begins, and moved to `catalog/ready-to-use/` when the demo contract is fully satisfied.

_No demos currently in development._

To start a new demo, open a GitHub Issue of type `demo:new` and follow the workflow in `AGENTS.md`.
