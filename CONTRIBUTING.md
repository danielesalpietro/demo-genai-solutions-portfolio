# Contributing

1. Open or select a GitHub Issue.
2. Agree acceptance criteria before implementation.
3. Branch from `main` using `feat/`, `fix/`, `docs/`, `security/`, or `chore/`.
4. Follow `AGENTS.md` and the demo contract.
5. Run `make validate` and `make smoke DEMO=<name>`.
6. Open a Pull Request and include evidence.
7. Resolve review comments and required checks. Use squash merge.

Do not report vulnerabilities in public Issues. Follow `SECURITY.md`.
